# Lab Task 06 - Abstract Data Types (ADT)

## Overview & Objective
This repository contains the implementation of Abstract Data Types (ADTs), data encapsulation, and abstraction principles using Java and JUnit in fulfillment of Software Construction (Lab 06).

## Tasks Implemented
1. **Lab Task 1 - Stack ADT**: Implemented an array-based LIFO stack (`ArrayStack`) and verified `pop()` behavior.
2. **Lab Task 2 - Data Encapsulation**: Created a `Student` class with private fields and public getters, enforcing encapsulation.
3. **Lab Task 3 - Programming to an Abstraction**: Demonstrated polymorphism by referencing `ArrayList` and `LinkedList` through the `List` interface.
4. **Lab Task 4 - Library System ADT Design**: Designed a `LibrarySystem` contract interface and implemented it using a `HashMap` collection.
5. **Lab Task 5 - Student Management System**: Implemented the `StudentCollection` ADT with unit tests validating search, addition, and removal.

## How to Run
1. Open the project in Apache NetBeans[cite: 2].
2. Run test files directly by selecting **Test File** (`Ctrl + F6`)[cite: 5].
